☕ Café do Corinthians

Este projeto consiste em um site de uma cafeteria temática inspirada no Sport Club Corinthians Paulista.

A proposta é criar uma experiência digital voltada aos torcedores do Corinthians, apresentando uma cafeteria com identidade visual inspirada no clube. O site permite conhecer o estabelecimento, seus produtos e o ambiente temático, unindo a paixão pelo futebol à experiência de uma cafeteria.

O projeto busca proporcionar uma experiência diferenciada aos torcedores, criando um espaço que combina café, cultura esportiva e a identidade do Corinthians.
